# Laboratorios de código

Organizar por semana y proyecto. Cada laboratorio debe incluir:
- Objetivo y requisitos.
- Entorno e instalación.
- Código fuente.
- Archivo `.env.example` sin secretos.
- Pruebas y datos de ejemplo no sensibles.
- Instrucciones para ejecutar.
- Limitaciones y próximos pasos.

Nunca subir API keys, tokens, contraseñas, datos personales ni información confidencial de empresas.
