# Currículo oficial — 10 semanas

**Meta:** desarrollar competencias prácticas para diseñar, programar, evaluar y desplegar aplicaciones de IA, Skills, agentes y sistemas multiagente en ecosistemas Claude y GPT.

| Semana | Tema | Entregable principal |
|---|---|---|
| 1 | Fundamentos de LLM y arquitectura de IA | Mapa de arquitectura de una aplicación inteligente |
| 2 | Python, JSON, HTTP, APIs REST y Git | Programa que consume un modelo mediante API |
| 3 | Prompt Engineering y Context Engineering | Motor de instrucciones portable |
| 4 | Desarrollo de Skills | Skill Factory con tres Skills probadas |
| 5 | Desarrollo de agentes y tool calling | Primer agente programado |
| 6 | Sistemas multiagente | Supervisor y tres agentes especialistas |
| 7 | MCP e integraciones | Agente conectado a herramientas/fuentes externas |
| 8 | RAG y conocimiento empresarial | Asistente documental fundamentado |
| 9 | Aplicaciones, evaluación y despliegue | Aplicación funcional con observabilidad básica |
| 10 | Arquitectura AI-First y proyecto final | QUIMA LABS AI Agent Framework |

## Dedicación semanal
8–10 horas: 2 h fundamentos, 3 h laboratorio guiado, 3 h desarrollo independiente, 1 h evaluación Feynman y 1 h experimentación/revisión.

## Reglas de avance
- No avanzar solo por haber leído el contenido.
- Cada semana requiere explicación Feynman, práctica verificable y evaluación.
- Umbral orientativo de aprobación: 80/100.
- Si hay brechas, crear un plan de refuerzo antes de avanzar.
- Distinguir siempre entre capacidades nativas de una plataforma, integraciones disponibles y código propio.
- Verificar documentación oficial vigente antes de depender de SDKs, APIs, funciones o límites que cambian con el tiempo.

## Proyecto integrador
QUIMA LABS AI Agent Framework: arquitectura modular con orquestador, motor de Skills, agentes, conocimiento/RAG e integraciones. Casos de uso: ingeniería y extracción de BOM desde planos, IT Operations y Business Intelligence. No asumir que un plano DWG puede interpretarse directamente por cualquier LLM: evaluar conversión, extracción CAD, geometría, metadatos y validación especializada.
