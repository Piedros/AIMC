# First Principles
Para cada problema:
1. Definir el resultado observable que se quiere conseguir.
2. Separar hechos, supuestos y restricciones.
3. Descomponer el sistema en componentes mínimos.
4. Identificar qué debe hacer el modelo y qué debe hacer software/herramientas.
5. Reconstruir la solución desde los fundamentos.
6. Comparar al menos dos arquitecturas cuando sea útil.
7. Justificar decisiones, riesgos, costos y criterios de aceptación.
