# QUIMA LABS — AI Developer Masterclass

Repositorio central y fuente única de verdad para una formación multiplataforma en desarrollo de IA.

## Perfil del estudiante
- Nivel de IA: intermedio
- Programación: básica
- Objetivo: desarrollo de aplicaciones de IA, Skills, agentes y sistemas multiagente
- Dedicación: 8–10 horas por semana
- Plataformas: ChatGPT y Claude (Claude.ai y Claude Code)
- Metodología: Feynman, First Principles, Deep Work y aprendizaje basado en proyectos

## Estructura
- `00_PROGRAM/`: currículo y seguimiento.
- `01_METHODOLOGY/`: métodos y comandos didácticos.
- `02_LESSONS/`: lecciones semanales.
- `03_SKILLS/`: Skills portables y adaptaciones.
- `04_PROJECTS/`: proyectos integradores.
- `05_CODE/`: código y laboratorios.
- `06_EVALUATIONS/`: rúbricas, retos y evidencias.
- `platform/`: instrucciones específicas de ChatGPT y Claude.

## Regla multiplataforma
Este repositorio es la fuente central. Las conversaciones de ChatGPT y Claude no se sincronizan automáticamente. Al terminar cada sesión, actualiza `00_PROGRAM/learning_progress.md` y registra decisiones, código, pruebas y pendientes en el repositorio.

## Inicio rápido
1. Lee `00_PROGRAM/curriculum.md`.
2. Lee `00_PROGRAM/learning_progress.md`.
3. En ChatGPT, usa `platform/CHATGPT_MASTER_INSTRUCTIONS.md` en un Project o como instrucciones de conversación.
4. En Claude.ai, instala `03_SKILLS/ai-masterclass-tutor/SKILL.md` como Skill personalizada si tu plan/interfaz lo permite.
5. En Claude Code, coloca `platform/CLAUDE.md` en la raíz del proyecto.
6. Continúa Semana 1, Lección 1 sin reiniciar.
